用途：手工验收工具行删除、消息操作、费用统计与安全围栏；全部勾选后再对外发布。

## A. 工具行删除（问行之外的新入口）

### A1 定位与识别

- [ ] 在会话中找到一条**工具调用**（不是提问、不是回答），其 DOM 满足 `[data-chat-flow-kind="tool-call"][data-chat-node-key]`。
- [ ] `data-chat-node-key` 形如 `9:tool-call<callId>`，`<callId>` 非空；同一行不会被误判成普通回复。
- [ ] 鼠标悬停该行，右侧出现**一个**红色危险样式按钮，图标为垃圾桶，`title` / `aria-label` 均为「删除该工具行」。

### A2 点击与确认

- [ ] 点击后立即弹出「确认操作」弹窗，正文为「删除该工具行？同一步的其它工具结果会一并删除，删除后不可恢复。」
- [ ] 弹窗按钮为「取消」「确认」；点取消、按 Esc、点遮罩空白处，弹窗关闭且**没有**任何内容消失。
- [ ] 弹窗打开时按 `Enter` 等同点「确认」（同一处理函数），动作只执行一次，不重复发请求。
- [ ] 「操作确认」开关关闭后，再点同一按钮**直接执行**，不再弹窗；改回开启后恢复弹窗。

### A3 删除结果

- [ ] 点「确认」后，被点的工具行立即从界面消失（乐观隐藏）；刷新快照后 `goneTools` 含该 `callId`。
- [ ] 宿主刷新后，同一 `(turn, step)` **整 step**（该步的答行、其它工具结果）一并被遮蔽；其它 step 完整保留。
- [ ] 该轮其它步骤的提问、回答、工具行不受影响；其它轮次不受影响。
- [ ] 侧边栏刻度：若整轮仍有可见内容，刻度保留；若该轮已无可见行，对应刻度隐藏且空隙收拢。
- [ ] **四步不复活**：删除工具行后，依次做 ① 刷新页面 ② 切到另一个对话再切回 ③ 重启 DSH 再打开该会话 ④ 再刷新；四步后被删工具行均不出现。
- [ ] **重启验证**：完全退出 DSH 再启动，打开原会话，被删内容仍不在界面 / 上下文 / 导出中（墓碑随会话日志持久化）。
- [ ] 对已删除目标再次点删除（或复用旧 seq 调接口）→ 提示「目标消息不存在或已被删除」；日志只新增一条正常事件，不出现第二块墓碑。
- [ ] 不做答行单独删除；答行上不应出现新的删除入口。

### A4 边界与失败

- [ ] 生成回复期间（会话根节点存在 `[data-chat-running]`），工具行按钮置灰不可点。
- [ ] 「删除」开关关闭后，工具行按钮消失；重新开启后恢复。
- [ ] 工具事件缺少 `callId`，或摘要里找不到对应 `callId` 行时，点按钮只提示「操作失败」，不猜测目标、不误删。
- [ ] 同一步节点在表面上不连续时，提示「目标回答与工具结果不连续，无法整体删除」，内容不变。
- [ ] 宿主 DOM 改版（找不到工具行）时按钮不出现；不出现按钮即不做任何删除。

### A5 与问行入口的区别

| 项 | 问行 | 工具行 |
|---|---|---|
| 悬停位置 | 提问行右侧 | 工具调用行右侧 |
| 按钮 | 撤回 / 分享 / 导出 / 删除 / 删至末尾 | 删除该工具行 |
| 作用范围 | 整轮 `turn` | 该 `(turn, step)` 的全部节点 |
| 删除后 | 内容消失；撤回会回填输入框 | 内容消失；不回填 |
| 开关 | 各自独立开关 | 受「删除」开关控制 |
| 运行中 | 全部置灰 | 置灰 |

## B. 消息操作回归（问行）

### B1 入口与文案

- [ ] 悬停任意提问行，右侧依次出现：撤回、分享、导出、删除、删至末尾。
- [ ] 按钮 `title` / `aria-label` 与界面语言一致；中文为上述五项，英文为 `Recall / Share / Export / Delete / Delete to end`。
- [ ] 删除、删至末尾为危险样式；撤回、分享、导出为普通样式。
- [ ] 各开关关闭时，对应按钮不出现；重新开启后出现。

### B2 撤回

- [ ] 点「撤回」弹出确认：`撤回该提问及其整轮回答？原文将回填到输入框。`
- [ ] 确认后整轮问答消失，被点那条提问的原文回填到输入框并聚焦，可直接修改再发。
- [ ] 若找不到输入框，退化为复制到剪贴板并提示「已复制到剪贴板」；剪贴板也不可用时提示「操作失败」。
- [ ] 回填取被点那条提问的原文；轮次区间起点是运行时注入消息时，不会误取起点正文。

### B3 删除整轮 / 删至末尾

- [ ] 「删除」确认文案：`删除该提问及其整轮回答？删除后不可恢复。` 确认后整轮消失。
- [ ] 「删至末尾」确认文案：`删除从该提问到对话末尾的全部内容？删除后不可恢复。` 确认后从该条起到末尾全部消失。
- [ ] 两者都不支持撤销；删除后刷新、切换对话再切回、重启 DSH 后结果均保持（与工具行同一套墓碑 / `goneTools` 逻辑）。
- [ ] 删除后侧边栏对应刻度隐藏并收拢空隙；不留可点击的幽灵条目。

### B4 分享 / 导出

- [ ] 点「分享」或「导出」直接打开全屏遮罩上的选择面板（不弹确认框）。
- [ ] 面板每张卡片显示该轮「问」「答」的单行预览（最多 200 字符），默认选中触发按钮所在轮。
- [ ] 可单选 / 多选 / 全选；没有可导出内容时显示「没有可导出的内容」且主按钮不可用。
- [ ] 分享：点「生成图片」后才按选中轮次拉全文，生成长图 PNG；内容过高时提示「内容过多，无法生成图片」。
- [ ] 导出：点「导出」下载 `dsh-{sessionId}-{YYYYMMDD-HHmm}.md`，正文含「问 / 答」结构，不含 system / developer / 工具结果正文。
- [ ] 分享图与导出内容只含真实提问与助手回答；运行时上下文不混入。
- [ ] 分享浮层按 `Enter` = 生成图片（`Share image`）；导出浮层按 `Enter` = 导出（`Export`）；`Esc` = 关闭。
- [ ] 浮层内焦点在输入控件时按 `Enter` 不触发主操作；无选中轮次 / 生成中按 `Enter` 不发起请求、不额外报错。
- [ ] 关闭浮层后再按 `Enter` 不触发插件动作；浮层内主按钮有可见焦点环。

### B5 回答统计

- [ ] 「回答统计」开启时，每条有内容的回答下方显示 `tokens · 字数`（形如 `1.2k tok · 120 字`；无 usage 时只显示字数）。
- [ ] 悬停显示完整提示「回答 {tokens} tokens · {words} 字」。
- [ ] 关闭开关后统计消失；重新开启后恢复。
- [ ] 字数由摘要接口给出，客户端不重复扫描正文。

### B6 运行中与失败

- [ ] 生成回复期间问行、工具行所有按钮置灰；分享 / 导出入口同样不可用。
- [ ] 生成中强行触发动作返回「正在生成回复，请稍后再试」。
- [ ] 网络中断 / 请求超过 15 秒时提示「操作失败」，页面不挂起、不出现未捕获异常。

## C. 设置、费用与安全

### C1 设置页结构

- [ ] 设置页只有一个「消息费用」导航项（英文 `Messages & Cost`）。
- [ ] 页内两个标签：**消息操作**、**费用统计**；切换标签不丢状态。
- [ ] 「消息操作」标签底部右侧显示小号、不可点击的 `v0.2.1`；「费用统计」标签不显示版本号。
- [ ] 所有开关 / 分段按钮改动即时保存并生效；保存失败时页内显示「无法保存设置」。

### C2 消息操作标签（7 项，顺序固定）

- [ ] 撤回、分享、导出、删除、删至末尾、操作确认、回答统计，顺序与文案如界面所示。
- [ ] 「操作确认」关闭后，撤回与删除类动作都直接执行；开启后撤回、删除、删至末尾、工具行删除均弹确认。
- [ ] 「删除」同时控制问行删除与工具行删除入口。

### C3 费用统计标签（5 项 + 校正）

- [ ] 费用统计（总开关）：侧边栏显示余额 / 日用 / 单次；关闭后卡片不渲染。
- [ ] 计费样式：`单行样式`（默认，无背景、单行居左）/ `多行样式`（带背景卡片与峰谷文字行）；切换即时生效并持久保存。
- [ ] 老配置 `costLayout: "default"` 升级后仍为多行样式；未配置过的新用户默认单行样式。
- [ ] 单次消耗：每轮结束后显示本轮金额；关闭后不渲染该组。
- [ ] 自动关闭：0–600 秒；0 = 常驻；设为 6 秒时，金额约 6 秒后整组隐藏。
- [ ] 峰谷定价行：显示当前时段与下一次切换（如「谷价 · 明日 9:00 起高峰」）。
- [ ] 余额校正：公式为「校正后余额 = 基线 − 已观测消费 + 实际累计到账 − 非调用扣减」；两项均为累计口径、覆盖保存；允许结果为负。
- [ ] 金额校验：最多两位小数、≥ 0、≤ 10000000；非法时提示「金额不合法：最多两位小数、≥ 0、≤ 10000000」。
- [ ] 保存失败提示「保存失败，请稍后再试」；校正值与账户差异过大时提示「与账户实际余额差异较大，请复核校正值」。

### C4 费用卡片

- [ ] 单行样式显示：余额、日用、单次；多行样式额外显示峰谷文字行。
- [ ] 余额点击可强制刷新；普通轮询受最短 60 秒间隔限制，不会更频繁地向账户服务取数。
- [ ] 余额旁「待核对」在余额上升时出现，title 指向「设置 → 消息费用 → 费用统计 → 余额校正」；保存校正后消失。
- [ ] 未登录显示「未登录」；仅配置 API key 显示「API key」；服务不可用显示「不可用」；沿用旧值显示「沿用中」并提示最近更新时间。
- [ ] 本地模型 / 非 DeepSeek 路由收起为「本地模型 · 无需计费」；切回 DeepSeek 后下一轮恢复收费态。
- [ ] 极小金额显示 `<¥0.01`，不得出现科学计数法或过长小数。
- [ ] 侧边栏收起时降级为钱币图标，悬停显示「余额 {balance}」。
- [ ] 峰谷：工作日 `09:00–12:00`、`14:00–18:00` 为高峰（橙 `#c2610b`），其余为谷价（蓝 `#2563b8`），谷价为高峰的 `0.5` 倍；周末按谷价处理。
- [ ] 状态图标为 14px SVG。

### C5 关闭总开关后的行为

- [ ] 关闭「费用统计」后：卡片消失、客户端不再发起费用请求、宿主停止余额取数与按轮记账。
- [ ] 重新开启后从当前余额继续，不补记关闭期间的差额；重启后设置保持。
- [ ] 关闭期间不产生新的余额请求（宿主日志 / 网络面板可验证）。

### C6 语言

- [ ] 切换 DSH 语言后，按钮、确认框、选择面板、统计提示、设置项、费用卡片文案随之切换。
- [ ] 中英文案与 `src/i18n.cjs` 一致，不出现混排或未翻译键名。
- [ ] 英文界面无溢出：侧边栏三列显示 `Bal / Today / Turn`，无省略号；`Local · no billing`；工具行按钮 `Delete tool`；设置项 `Style` / `Per-turn` / `Auto-hide` / `Peak/off-peak`；校正区 `Balance correction` / `Pending adj.` / `Save`；均不被截断或换行。
- [ ] 中文界面文案与英文精简前一致（`余额` / `单次消耗` / `计费样式` / `生成图片` / `操作确认` / `删除该工具行` 等未改）。

### C7 安全围栏

- [ ] 跨站页面发起 `POST /dsh-message-actions`、`GET /messages`、`GET /cost/state` → `403`。
- [ ] 非回环 `Host` → `403`；`Sec-Fetch-Site: cross-site` / `same-site` → 拒绝。
- [ ] 带 `Origin` 且与宿主不同源 → 拒绝；宿主给不出期望 `Origin` 时带 `Origin` 的请求一律拒绝。
- [ ] JSON 响应头含 `cache-control: no-store`、`x-content-type-options: nosniff`、`referrer-policy: no-referrer`、`cross-origin-resource-policy: same-origin`、`content-security-policy: default-src 'none'; frame-ancestors 'none'`。
- [ ] 写请求只接受 `content-type: application/json`；体超过 1MB → `413` 并排空连接；方法不匹配 → `405` 且带 `allow`。
- [ ] `/messages` 摘要只含 id / turn / step / 最多 200 字符预览 / 用量 / `callId`；system、developer、运行时上下文、工具结果正文一律为空。
- [ ] `full=1&turns=` 只返回选中轮次的问 / 答全文。
- [ ] 状态文件超 4MB 自动重建并记录含大小与阈值的 warn；未超限但损坏时改名 `cost-state.bad-<时间戳>.json`。

## D. 失败提示表

| 提示文案（中文） | 触发场景 | 预期 |
|---|---|---|
| 操作失败 | 网络中断、请求超过 15 秒、`callId` 解析失败、摘要缺少对应行、输入框回填失败且剪贴板不可用 | 有提示，不误删，不挂起 |
| 正在生成回复，请稍后再试 | 生成回复期间触发动作 | 动作不执行，按钮通常已置灰 |
| 目标消息不存在或已被删除 | 目标 seq 不在表面、已被墓碑遮蔽，或重复删除 / 撤回 | 不执行，提示后保持原样；不写第二块墓碑 |
| 该消息不可删除 | 系统消息 / 节点 0 / 缺少 turn 或 step | 不执行 |
| 仅用户消息可撤回 | 对非用户消息执行撤回 | 不执行 |
| 目标回答与工具结果不连续，无法整体删除 | 同 step 节点在表面上不连续 | 不执行，内容不变 |
| 会话不可用 | 会话已关闭或不可写 | 不执行 |
| 请求被拒绝 | 跨站 / 非回环 Host / Origin 不符 | 返回 403，UI 显示对应文案 |
| 无效请求 | 请求体为空或 JSON 非法 | 返回 400 |
| 请求体过大 | 超过 1MB | 返回 413 并排空连接 |
| 内部错误 | 未捕获的服务端异常 | 返回 500，日志有 warn |
| 没有可导出的内容 | 选择面板无轮次 | 主按钮不可用 |
| 内容过多，无法生成图片 | 长图超过高度上限（12000px） | 不生成，提示后留在面板 |
| 已复制到剪贴板 | 找不到输入框，撤回回填退化为复制 | 文本进入剪贴板 |
| 无法保存设置 | 设置保存失败 | 页内错误提示 |
| 金额不合法：最多两位小数、≥ 0、≤ 10000000 | 校正输入非法 | 不保存 |
| 保存失败，请稍后再试 | 校正保存失败 | 不落盘，表单保留 |
| 与账户实际余额差异较大，请复核校正值 | 校正结果与账户余额差异过大 | 允许保存但提示复核 |
